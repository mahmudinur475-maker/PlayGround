# PlayGround

## 🏁 Lomba Lari

A mobile-first 320-metre stadium sprint for phones, tablets, and desktop. Race three AI runners through four lanes, hop hurdles, slide under barriers, dodge cones, and grab energy orbs to fire the turbo.

- **Touch:** swipe left/right to change lanes, swipe up or tap to jump, swipe down or hold **LUNCUR** to slide, hold **TURBO** to sprint.
- **Keyboard:** `A` / `D` change lanes, `W` or `Space` jumps, `S` slides, `Shift` sprints.
- **Tilt (optional):** enable *Kemudi miring* in the menu and tilt the phone to steer. On iOS the motion permission prompt appears when it is enabled.
- **Goal:** finish first, set a personal best, and beat the three rivals. Best time and win count are stored locally in the browser.

No build step or dependencies are required. Serve the folder with any static file server and open `index.html`.

### Project layout

- `index.html` — menu, HUD, modals, results
- `styles.css` — responsive layout and visual system
- `src/game.js` — race state, physics, AI, collisions, tilt
- `src/renderer.js` — perspective track, stadium, runners, effects
- `src/course.js` — lanes, hazards, rival blueprints
- `src/audio.js` — synthesized WebAudio ambience and SFX
- `manifest.webmanifest` + `favicon.svg` — installable web-app metadata
